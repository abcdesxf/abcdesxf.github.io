# 课程学习笔记 - 二分图匹配

## A. T恤分配

这道题就是匈牙利算法的模板，但是还有另一种做法：

从小尺码到大尺码依次分配。

处理当前尺码时，把所有“最小可接受尺码不大于当前尺码”的队员加入候选集合。然后优先把衣服分给最大可接受尺码最小的人。

从 `S` 到 `T` 遍历：

1. 加入所有最小尺码等于当前尺码的队员。
2. 候选队员按照最大尺码从小到大排序。
3. 使用当前尺码的 T 恤，优先满足最大尺码最小的队员。
4. 如果当前尺码处理完后，仍有人最大只能接受当前尺码，则以后无法分配，输出 `NO`。
5. 最后所有人都被分配，则输出 `YES`。

代码（这个方法）：

```cpp
#include <bits/stdc++.h>
using namespace std;
string s, t;
int n, a[5][5], c[5], q[5];
int id(char c) {
    string s = "SMLXT";
    return s.find(c);
}
int main() {
    cin >> s >> n;
    for (int i = 0; i < n; i++) {
        cin >> t;
        a[id(t[0])][id(t[1])]++;
    }
    for (int &x : c) cin >> x;
    cin >> s;
    int ans = 0;
    for (int i = 0; i < 5; i++) {
        for (int j = i; j < 5; j++) {
            q[j] += a[i][j];
        }
        for (int j = i; j < 5 && c[i]; j++) {
            int x = min(c[i], q[j]);
            c[i] -= x;
            q[j] -= x;
            ans += x;
        }
        if (q[i]) {
            cout << "NO\n";
            return 0;
        }
    }
    cout << (ans == n ? "YES\n" : "NO\n");
    return 0;
}
```

代码（匈牙利）：

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, m, g[25][105], mt[105], vis[105], l[25], r[25], a[5], sz[105];
string s;
int id(char c) {
    return string("SMLXT").find(c);
}
bool dfs(int u) {
    for (int v = 0; v < m; v++) {
        if (!g[u][v] || vis[v]) continue;
        vis[v] = 1;
        if (mt[v] == -1 || dfs(mt[v])) {
            mt[v] = u;
            return true;
        }
    }
    return false;
}
int main() {
    cin >> s >> n;
    for (int i = 0; i < n; i++) {
        cin >> s;
        l[i] = id(s[0]);
        r[i] = id(s[1]);
    }
    for (int i = 0; i < 5; i++) cin >> a[i];
    cin >> s;
    for (int i = 0; i < 5; i++) {
        while (a[i]--) {
            sz[m++] = i;
        }
    }
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (l[i] <= sz[j] && sz[j] <= r[i]) {
                g[i][j] = 1;
            }
        }
    }
    memset(mt, -1, sizeof mt);
    int ans = 0;
    for (int i = 0; i < n; i++) {
        memset(vis, 0, sizeof vis);
        ans += dfs(i);
    }
    cout << (ans == n ? "YES" : "NO");
    return 0;
}
```

## B. 覆盖集合统计

先把选出的点集拆成 $X\subseteq A$ 和 $Y\subseteq B$。

一个匹配能够同时覆盖 $X,Y$，当且仅当：

1. 存在一个匹配覆盖 $X$ 中的所有点。
2. 存在一个匹配覆盖 $Y$ 中的所有点。

必要性显然。

充分性可以把两个匹配的并拆成若干条交替路径和交替环。在每个连通块内选择合适的一组交替边，就可以同时覆盖 $X$ 中的左部点与 $Y$ 中的右部点。

所以左右两边可以分开处理。

根据 Hall 定理，左部点集 $S$ 能够被匹配覆盖，当且仅当它的每个子集 $T$ 都满足：

$$
|N(T)|\ge |T|
$$

先枚举所有子集，找出满足 $|N(T)|<|T|$ 的坏集合。一个集合只要包含任意坏集合，就一定不合法。

使用高维前缀和的方式，把坏集合向它的所有超集传递，即可在 $O(n2^n)$ 内求出所有能够被匹配覆盖的左部点集。右部同理。

最后分别记录左右两边所有合法集合的权值和。将右边排序，枚举左边的权值和，二分统计有多少右边集合满足总权值不小于 $t$。

代码：

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const int N = 21, S = 1 << 20;
ll n, m, x[N], y[N], sm[S], sa[S], sb[S], t, ans;
unsigned a[N], b[N], ne[S];
char g[N][N], bad[S];
int sol(int n, unsigned a[], ll w[], ll r[]) {
    int z = 1 << n, c = 0;
    ne[0] = sm[0] = bad[0] = 0;
    for (int s = 1, i, p; s < z; s++) {
        i = __builtin_ctz(s), p = s ^ (1 << i);
        ne[s] = ne[p] | a[i], sm[s] = sm[p] + w[i];
        bad[s] = __builtin_popcount(ne[s]) < __builtin_popcount((unsigned)s);
    }
    for (int i = 0; i < n; i++) {
        for (int s = 0; s < z; s++) {
            if (s >> i & 1) bad[s] |= bad[s ^ (1 << i)];
        }
    }
    for (int s = 0; s < z; s++) if (!bad[s]) r[c++] = sm[s];
    return c;
}
int main() {
    cin >> n >> m;
    for (int i = 0; i < n; i++) {
        cin >> g[i];
    }
    for (int i = 0; i < n; i++) {
        cin >> x[i];
    }
    for (int i = 0; i < m; i++) {
        cin >> y[i];
    }
    cin >> t;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (g[i][j] == '1') {
                a[i] |= 1u << j, b[j] |= 1u << i;
            }
        }
    }
    int ca = sol(n, a, x, sa), cb = sol(m, b, y, sb);
    sort(sb, sb + cb);
    for (int i = 0; i < ca; i++) {
        ans += sb + cb - lower_bound(sb, sb + cb, t - sa[i]);
    }
    cout << ans;
    return 0;
}
```

## C. 套箱问题

如果箱子 $i$ 可以套进箱子 $j$，就在二分图中连接左部点 $i$ 与右部点 $j$。

每一条匹配边表示把一个小箱子直接放进一个大箱子。因为一个箱子最多直接包含一个箱子，同时也最多被一个箱子直接包含，所以这些关系恰好组成若干条链。

原问题就转化成了 DAG 的最小路径覆盖：最少箱子数 $=n \ -$ 二分图最大匹配数。

严格小于保证了套箱关系不会形成环。

代码：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 505;
int n, a[N][3], g[N][N], mt[N], vis[N];
bool dfs(int u) {
    for (int v = 1; v <= n; v++) {
        if (!g[u][v] || vis[v]) continue;
        vis[v] = 1;
        if (!mt[v] || dfs(mt[v])) {
            mt[v] = u;
            return true;
        }
    }
    return false;
}
int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i][0] >> a[i][1] >> a[i][2];
    }
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            g[i][j] = a[i][0] < a[j][0] && a[i][1] < a[j][1] && a[i][2] < a[j][2];
        }
    }
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        memset(vis, 0, sizeof vis);
        ans += dfs(i);
    }
    cout << n - ans;
    return 0;
}
```

## D. 放置大炮

把每一行看成左部点，每一列看成右部点。若 $(r,c)$ 上存在怪物，就在行 $r$ 与列 $c$ 之间连边。

在某一行或某一列放置大炮，相当于选择一个点；消灭所有怪物，相当于让每条边至少有一个端点被选择。

因此原问题就是求二分图最小点覆盖。

根据 König 定理：二分图最小点覆盖数 $=$ 二分图最大匹配数。

题目还要求输出方案。求出最大匹配后，从所有未匹配的左部点出发，只沿下面两类边搜索：

1. 从左部点沿非匹配边走到右部点。
2. 从右部点沿匹配边走到左部点。

设搜索到的左右部点集合分别为 $Z_L,Z_R$，则一组最小点覆盖为：

$$
(L-Z_L)\cup Z_R
$$

因为边数最多达到 $10^6$，普通匈牙利算法可能超时，这里使用 Hopcroft-Karp 算法求最大匹配。

代码：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 1000010;
int r, c, n, h[N], to[N], nx[N], ec, ml[N], mr[N], d[N], cur[N], q[N], zl[N], zr[N];
void add(int u, int v) {
    to[++ec] = v, nx[ec] = h[u], h[u] = ec;
}
bool bfs() {
    int l = 0, rr = 0;
    memset(d, -1, (r + 1) * sizeof(int));
    for (int i = 1; i <= r; i++) {
        if (!ml[i]) {
            d[i] = 0;
            q[rr++] = i;
        }
    }
    bool ok = false;
    while (l < rr) {
        int u = q[l++];
        for (int i = h[u], v, w; i; i = nx[i]) {
            v = to[i], w = mr[v];
            if (!w) ok = true;
            else if (d[w] == -1) {
                d[w] = d[u] + 1;
                q[rr++] = w;
            }
        }
    }
    return ok;
}
bool dfs(int u) {
    for (int &i = cur[u], v, w; i; i = nx[i]) {
        v = to[i], w = mr[v];
        if (!w || (d[w] == d[u] + 1 && dfs(w))) {
            ml[u] = v;
            mr[v] = u;
            return true;
        }
    }
    d[u] = -1;
    return false;
}
int main() {
    cin >> r >> c >> n;
    for (int i = 0, x, y; i < n; i++) {
        cin >> x >> y;
        add(x, y);
    }
    while (bfs()) {
        memcpy(cur, h, (r + 1) * sizeof(int));
        for (int i = 1; i <= r; i++) if (!ml[i]) dfs(i);
    }
    int l = 0, rr = 0;
    for (int i = 1; i <= r; i++) {
        if (!ml[i]) {
            zl[i] = 1;
            q[rr++] = i;
        }
    }
    while (l < rr) {
        int u = q[l++];
        for (int i = h[u], v; i; i = nx[i]) {
            v = to[i];
            if (ml[u] == v || zr[v]) continue;
            zr[v] = 1;
            if (mr[v] && !zl[mr[v]]) {
                zl[mr[v]] = 1;
                q[rr++] = mr[v];
            }
        }
    }
    int ans = 0;
    for (int i = 1; i <= r; i++) ans += !zl[i];
    for (int i = 1; i <= c; i++) ans += zr[i];
    cout << ans;
    for (int i = 1; i <= r; i++) if (!zl[i]) cout << " r" << i;
    for (int i = 1; i <= c; i++) if (zr[i]) cout << " c" << i;
    return 0;
}
```

## E. 军队演习

同一队中的朋友不会影响公平性，所以只保留红队与蓝队之间的朋友关系。

把蓝队看成左部点，红队看成右部点，每一对跨队朋友连接一条边。删除一些队员，使跨队朋友关系全部消失，就是求这个二分图的最小点覆盖。

但是题目还要求在最小点覆盖中输出字典序最小的编号序列。

先求出一组最大匹配，设匹配数为 $k$。根据 König 定理，最小点覆盖的大小也是 $k$。

这 $k$ 条匹配边两两没有公共端点。任意大小为 $k$ 的点覆盖，都必须在每一条匹配边中恰好选择一个端点，并且不能选择未匹配点。

因此可以给每条匹配边设置一个布尔变量 $x_i$：

- $x_i=1$ 表示选择这条匹配边的蓝队端点。
- $x_i=0$ 表示选择这条匹配边的红队端点。

对于一条朋友边 $(u,v)$：

1. 如果两端都已匹配，就加入“选择 $u$ 或选择 $v$”的限制。
2. 如果蓝队端点未匹配，则红队端点必须选择。
3. 如果红队端点未匹配，则蓝队端点必须选择。

这些限制都是 2-SAT 子句。

接下来按照编号从小到大枚举队员。对于当前队员，优先尝试强制选择它；如果加入这个限制后 2-SAT 仍然有解，就保留这个选择，否则选择同一条匹配边的另一个端点。

因为所有答案的长度相同，在第一个不同的编号处选择较小编号，得到的就是字典序最小的序列。

代码：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 5010, M = 200010, V = N * 2, E = M * 2 + N;
int n, m, a[N], h[N], to[M], nx[M], ec, ml[N], mr[N], vis[N], tim, x[M], y[M], mc, il[N], ir[N], f[N], k, pu[M * 2], pv[M * 2], pc, hd[V], rh[V], et[E], en[E], rt[E], rn[E], se, vs[V], o[V], co[V], oc;
void add(int u, int v) {
    to[++ec] = v, nx[ec] = h[u], h[u] = ec;
}
bool dfs(int u) {
    for (int i = h[u], v; i; i = nx[i]) {
        v = to[i];
        if (vis[v] == tim) continue;
        vis[v] = tim;
        if (mr[v] == -1 || dfs(mr[v])) {
            ml[u] = v;
            mr[v] = u;
            return true;
        }
    }
    return false;
}
void ae(int u, int v) {
    et[++se] = v, en[se] = hd[u], hd[u] = se;
    rt[se] = u, rn[se] = rh[v], rh[v] = se;
}
void d1(int u) {
    vs[u] = 1;
    for (int i = hd[u]; i; i = en[i]) if (!vs[et[i]]) d1(et[i]);
    o[oc++] = u;
}
void d2(int u, int c) {
    co[u] = c;
    for (int i = rh[u]; i; i = rn[i]) if (co[rt[i]] == -1) d2(rt[i], c);
}
bool sat() {
    int v = k * 2, cc = 0;
    memset(hd, 0, v * sizeof(int));
    memset(rh, 0, v * sizeof(int));
    se = oc = 0;
    for (int i = 0; i < pc; i++) ae(pu[i], pv[i]);
    for (int i = 0; i < k; i++) if (f[i] != -1) {
        int z = i * 2 + f[i];
        ae(z ^ 1, z);
    }
    memset(vs, 0, v * sizeof(int));
    memset(co, -1, v * sizeof(int));
    for (int i = 0; i < v; i++) if (!vs[i]) d1(i);
    while (oc--) if (co[o[oc]] == -1) d2(o[oc], cc++);
    for (int i = 0; i < k; i++) if (co[i * 2] == co[i * 2 + 1]) return false;
    return true;
}
int main() {
    cin >> n >> m;
    for (int i = 0; i < n; i++) cin >> a[i];
    for (int i = 0, u, v; i < m; i++) {
        cin >> u >> v;
        if (a[u] == a[v]) continue;
        if (a[u]) swap(u, v);
        x[mc] = u, y[mc++] = v, add(u, v);
    }
    memset(ml, -1, sizeof ml);
    memset(mr, -1, sizeof mr);
    memset(il, -1, sizeof il);
    memset(ir, -1, sizeof ir);
    for (int i = 0; i < n; i++) if (!a[i]) ++tim, dfs(i);
    for (int i = 0; i < n; i++) {
        if (!a[i] && ml[i] != -1) il[i] = ir[ml[i]] = k++;
    }
    for (int i = 0, u, v, p, q; i < mc; i++) {
        u = x[i], v = y[i];
        if (il[u] == -1) {
            q = ir[v] * 2;
            pu[pc] = q ^ 1, pv[pc++] = q;
        } else if (ir[v] == -1) {
            p = il[u] * 2 + 1;
            pu[pc] = p ^ 1, pv[pc++] = p;
        } else {
            p = il[u] * 2 + 1, q = ir[v] * 2;
            pu[pc] = p ^ 1, pv[pc++] = q;
            pu[pc] = q ^ 1, pv[pc++] = p;
        }
    }
    memset(f, -1, sizeof f);
    for (int i = 0; i < n; i++) {
        int z = a[i] ? ir[i] : il[i];
        if (z == -1 || f[z] != -1) continue;
        f[z] = !a[i];
        if (!sat()) f[z] ^= 1;
    }
    cout << k;
    for (int i = 0; i < n; i++) {
        int z = a[i] ? ir[i] : il[i];
        if (z != -1 && f[z] == !a[i]) cout << ' ' << i;
    }
    return 0;
}
```

## F. 成绩调研

把每个学生看成一个区间 $[X_i,Y_i]$，如果学生说真话，就要在这个区间中给他分配一个排名，并且不同学生的排名不能相同。

对于一个给定的学生集合，按照 $Y_i$ 从小到大排序。依次给每个学生分配不小于 $X_i$ 的最小未使用排名；如果这个排名不超过 $Y_i$，就能加入匹配，否则跳过该学生。

这个贪心可以求出当前集合能够匹配的最大人数。因为右端点越小的区间越早失效，优先处理它不会影响后面右端点更大的区间。

设所有学生能够匹配的最大人数为 $ans$。为了得到字典序最大的编号序列，从编号 $1$ 到 $n$ 依次尝试删除学生：

1. 暂时删除当前学生。
2. 重新计算剩余学生最多能匹配多少人。
3. 如果仍然能匹配 $ans$ 人，就永久删除；否则恢复。

因为优先删除较小编号，所以最终保留的就是字典序最大的最优集合。

代码：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 65, M = 100005;
int n, x[N], y[N], p[N], on[N];
char vis[M];
bool cmp(int a, int b) {
    return y[a] < y[b];
}
int cal() {
    int c = 0, ans = 0;
    memset(vis, 0, sizeof vis);
    for (int i = 1; i <= n; i++) if (on[i]) p[c++] = i;
    sort(p, p + c, cmp);
    for (int i = 0, z; i < c; i++) {
        z = x[p[i]];
        while (z <= y[p[i]] && vis[z]) z++;
        if (z <= y[p[i]]) vis[z] = 1, ans++;
    }
    return ans;
}
int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> x[i] >> y[i], on[i] = 1;
    int ans = cal();
    for (int i = 1; i <= n; i++) {
        on[i] = 0;
        if (cal() < ans) on[i] = 1;
    }
    cout << ans << '\n';
    for (int i = 1; i <= n; i++) if (on[i]) cout << i << ' ';
    return 0;
}
```

## G. 选配课代表

把课程看成左部点，学生看成右部点。如果学生对某门课程感兴趣，就在这门课程与该学生之间连边。

每名学生至多担任一门课代表，每门课程至多选择一名学生，正好对应二分图匹配。

使用匈牙利算法求最大匹配。如果最大匹配数等于课程数 $P$，说明每门课程都能选到不同的课代表，输出 `YES`，否则输出 `NO`。

代码：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int P = 105, N = 305;
int p, n, g[P][N], mt[N], vis[N];
bool dfs(int u) {
    for (int v = 1; v <= n; v++) {
        if (!g[u][v] || vis[v]) continue;
        vis[v] = 1;
        if (!mt[v] || dfs(mt[v])) {
            mt[v] = u;
            return true;
        }
    }
    return false;
}
int main() {
    cin >> p >> n;
    for (int i = 1, k, x; i <= p; i++) {
        cin >> k;
        while (k--) cin >> x, g[i][x] = 1;
    }
    int ans = 0;
    for (int i = 1; i <= p; i++) {
        memset(vis, 0, sizeof vis);
        ans += dfs(i);
    }
    cout << (ans == p ? "YES" : "NO");
    return 0;
}
```
