# 课程学习笔记 - 树结构升级

本节围绕树形动态规划、换根动态规划、树上背包、同色连通块缩点以及树的直径展开。树上问题通常没有完全统一的状态设计，但核心方法较为稳定：先选定根节点，将无根树转化为有根树，再根据“子树内信息如何合并”以及“父节点信息如何下传”设计状态与转移。

## A. 间隔选点-树上版本

对应题目：[HDU 1520 - Anniversary party](https://acm.hdu.edu.cn/showproblem.php?pid=1520) or [没有上司的舞会](https://www.luogu.com.cn/problem/P1352)

### 题意简述

给出一棵包含 $n$ 个点的树以及 $n$ 个点的权值 $a_i$，需要选出一个点集，满足点集中任意两点之间没有边**直接**相连（可以间接相连），求能够选出点集中最大的点权和。

### 解题思路

定义 $dp_{i,\{0,1\}}$ 表示当前点选/不选的子树答案，那么根据题目可以推出转移式（$son(i)$ 返回 $i$ 的子节点集，下同）：
$$
dp_{i,0}\leftarrow dp_{i,0}+\sum_{j \ \in \ son(i)}\max(dp_{j,0},dp_{j,1})\\
dp_{i,1}\leftarrow dp_{i,1}+\sum_{j \ \in \ son(i)}dp_{j,0}
$$
根据转移式转移即可，注意在遍历新点时需初始化状态 $dp_{i,0}=0,dp_{i,1}=a_i$，以及遍历子节点时去除父亲。

### 复杂度分析

每个节点和每条边均只被处理常数次，时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。

### AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 6010;
int n, a[N], dp[N][2];
vector<int> G[N];
void dfs(int x, int fa) {
    dp[x][0] = 0;
    dp[x][1] = a[x];
    for (int y : G[x]) {
        if (y == fa) {
            continue;
        }
        dfs(y, x);
        dp[x][0] += max(dp[y][0], dp[y][1]);
        dp[x][1] += dp[y][0];
    }
}
int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        G[u].push_back(v);
        G[v].push_back(u);
    }
    dfs(1, 0);
    cout << max(dp[1][0], dp[1][1]) << '\n';
    return 0;
}
```

## B. 苹果树

对应题目：[2486 -- Apple Tree](http://poj.org/problem?id=2486) or [Apple Tree - POJ 2486 - Virtual Judge](https://vjudge.net/problem/POJ-2486)

### 题意简述

给定一棵 $n$ 个节点的树，节点带权。从节点 $1$ 出发，最多移动 $k$ 条边，同一条边允许重复经过，求访问到的不同节点的最大点权和。

### 解题思路

设 $dp_{i,j,0}$ 表示从 $i$ 出发，在其子树内移动 $j$ 步且最终回到 $i$ 时能够获得的最大点权和；$dp_{i,j,1}$ 表示移动 $j$ 步且最终不必回到 $i$ 时的最大点权和。

答案即 $\max_{i=1}^k(dp_{1,i,1})$。（$dp_{\cdots,0}$ 被包含在 $dp_{\cdots,1}$ 里面了）

转移式：
$$
dp_{x,i+j+2,0}\leftarrow \max(dp_{x,i+j+2,0},dp_{x,i,0}+dp_{y,j,0})
\\
dp_{x,i+j+2,1}\leftarrow \max(dp_{x,i+j+2,1},dp_{x,i,1}+dp_{y,j,0})
\\
dp_{x,i+j+1,1}\leftarrow \max(dp_{x,i+j+1,1},dp_{x,i,0}+dp_{y,j,1})
\\
(y\in son(x),i\in[0,k],j\in[0,k-i-\{1,2\}])
$$
解释：

对于第一个转移，路径需要回到 $x$，那么可拆分为：$x$ 的其他子树（$dp_{x,i,0}$），$y$ 的子树（$dp_{y,j,0}$）以及 $x,y$ 之间的两次往返（$i+j+\Large2$）。

对于第二个转移，在第一个转移的基础上将其他子树调为无需返回，相当于：$x\rightarrow y\rightarrow dp_{y,j,0}\rightarrow y\rightarrow x\rightarrow dp_{x,i,1}$（可以看出同样 $x\rightarrow y$ 两次）。

对于第三个转移，因为原状态的 ${0/1}$ 由 $y$ 的子树决定，所以原状态为 $1$，相当于：$x\rightarrow dp_{x,i,0}\rightarrow x\rightarrow y\rightarrow dp_{y,j,1}$（可以看出 $x\rightarrow y$ 仅一次）。

注意因为更新会影响到后面的状态，所以需要倒序更新（类似背包，具体见代码）。

### 复杂度分析

每个节点在合并子树时枚举两部分步数，时间复杂度为 $O(nk^2)$，空间复杂度为 $O(nk)$。

### AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const int INF = 1000000000;
int n, k, a[110], dp[110][210][2];
vector<int> G[110];
void dfs(int x, int fa) {
    for (int i = 0; i <= k; i++) {
        dp[x][i][0] = dp[x][i][1] = -INF;
    }
    dp[x][0][0] = dp[x][0][1] = a[x];
    for (auto y : G[x]) {
        if (y == fa) continue;
        dfs(y, x);
        for (int i = k; i >= 0; i--) {
            for (int j = 0; i + j + 2 <= k; j++) {
                dp[x][i + j + 2][0] = max(dp[x][i + j + 2][0], dp[x][i][0] + dp[y][j][0]);
                dp[x][i + j + 2][1] = max(dp[x][i + j + 2][1], dp[x][i][1] + dp[y][j][0]);
            }
            for (int j = 0; i + j + 1 <= k; j++) {
                dp[x][i + j + 1][1] = max(dp[x][i + j + 1][1], dp[x][i][0] + dp[y][j][1]);
            }
        }
    }
}
int main() {
    cin >> n >> k;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    for (int i = 1, x, y; i < n; i++) {
        cin >> x >> y;
        G[x].push_back(y);
        G[y].push_back(x);
    }
    dfs(1, 0);
    int mx = 0;
    for (int i = 0; i <= k; i++) {
        mx = max(mx, dp[1][i][1]);
    }
    cout << mx;
    return 0;
}
```

## C. 树上最远距离

对应题目：[Problem - 2196](https://acm.hdu.edu.cn/showproblem.php?pid=2196) or [Computer - HDU 2196 - Virtual Judge](https://vjudge.net/problem/HDU-2196)

### 题意简述

给出一棵 $n$ 个节点的树，求每个节点能够到达的最远节点与其的距离。

### 解题思路

发现一个点的最远点只有两种情况：一种是在该点子树内，一种是在子树外。

那么可以维护 $d1,d2$ 表示子树内的最大与次大，$up$ 表示子树外的最大，用 $dfs$ 维护即可。

更具体地，第一次 DFS 自底向上计算每个节点向子树方向延伸的最大距离 $d1$ 和次大距离 $d2$，并记录最大距离来自哪个子节点。第二次 DFS 自顶向下计算 $up$：当最大子树贡献来自当前子节点时，必须改用次大值，否则会重复进入该子节点的子树。

节点 $u$ 的最终答案为 $\max(d1_u,up_u)$。这一过程是典型的换根动态规划。

### 复杂度分析

两次 DFS 均为线性遍历，时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。

### AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int n, d1[10010], d2[10010], up[10010], son[10010];
vector<pair<int, int>> G[10010];
void dfs1(int u, int fa) {
    for (auto x : G[u]) {
        int v = x.first, w = x.second;
        if (v == fa) continue;
        dfs1(v, u);
        int val = d1[v] + w;
        if (val > d1[u]) {
            d2[u] = d1[u];
            d1[u] = val;
            son[u] = v;
        } else if (val > d2[u]) {
            d2[u] = val;
        }
    }
}
void dfs2(int u, int fa) {
    for (auto x : G[u]) {
        int v = x.first, w = x.second;
        if (v == fa) continue;
        up[v] = max(up[u], (son[u] == v ? d2[u] : d1[u])) + w;
        dfs2(v, u);
    }
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    while (cin >> n) {
        for (int i = 1; i <= n; i++) {
            G[i].clear();
            d1[i] = d2[i] = up[i] = son[i] = 0;
        }
        for (int i = 2, parent, weight; i <= n; i++) {
            cin >> parent >> weight;
            G[parent].push_back({i, weight});
            G[i].push_back({parent, weight});
        }
        dfs1(1, 0);
        dfs2(1, 0);
        for (int i = 1; i <= n; i++) {
            cout << max(d1[i], up[i]) << '\n';
        }
    }
    return 0;
}
```

## D. 机器扫边

对应题目：[HDU 4003 - Find Metal Mineral](https://acm.hdu.edu.cn/showproblem.php?pid=4003) or [Virtual Judge](https://vjudge.net/problem/HDU-4003)

### 题意简述

给定一棵包含 $n$ 个节点的带权树，有 $k$ 个机器人从节点 $s$ 同时出发。要求所有边都至少被一个机器人经过，机器人不必返回起点，求所有机器人移动距离之和的最小值。

### 解题思路

以 $s$ 为根。定义 $dp_{u,j}$ 表示遍历完节点 $u$ 的整棵子树，并且最终有 $j$ 个机器人停留在该子树内时的最小代价。

处理叶节点时，不需要经过任何子树边，因此对任意 $j$ 都有 $dp_{u,j}=0$。

考虑合并 $u$ 的一个子节点 $v$，边权为 $w$。设总共需要在合并后的子树中留下 $j$ 个机器人，其中有 $p$ 个机器人进入 $v$ 的子树：

1. 当 $p=0$ 时，仍然需要遍历 $v$ 的子树，但进入该子树的机器人最后必须返回 $u$，边 $(u,v)$ 会被经过两次，代价增加 $dp_{v,0}+2w$；
2. 当 $p>0$ 时，有 $p$ 个机器人最终停留在 $v$ 的子树中。这 $p$ 个机器人都需要从 $u$ 经过边 $(u,v)$，代价增加 $dp_{v,p}+pw$。

因此，树上分组背包转移为：

$$
nw_j=\min\left(dp_{u,j}+dp_{v,0}+2w,\min_{1\le p\le j}\{dp_{u,j-p}+dp_{v,p}+pw\}\right)
$$

每次合并必须使用临时数组，避免本轮已经更新的状态再次参与转移。最终答案为 $dp_{s,k}$。

### 复杂度分析

每次合并枚举当前机器人数量和分配给子树的机器人数量，时间复杂度为 $O(nk^2)$，空间复杂度为 $O(nk)$。

### AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 10010, K = 12, INF = 0x3f3f3f3f;
struct Edge {
    int to, w;
};
int n, s, cnt, dp[N][K];
vector<Edge> G[N];
void dfs(int x, int fa) {
    for (int j = 0; j <= cnt; j++) {
        dp[x][j] = 0;
    }
    for (auto e : G[x]) {
        int y = e.to, w = e.w;
        if (y == fa) continue;
        dfs(y, x);
        int nxt[K];
        fill(nxt, nxt + cnt + 1, INF);
        for (int j = 0; j <= cnt; j++) {
            nxt[j] = min(nxt[j], dp[x][j] + dp[y][0] + 2 * w);
            for (int k = 1; k <= j; k++) {
                nxt[j] = min(nxt[j], dp[x][j - k] + dp[y][k] + k * w);
            }
        }
        for (int j = 0; j <= cnt; j++) {
            dp[x][j] = nxt[j];
        }
    }
}
int main() {
    int T = 1;
    // cin >> T;
    while (T--) {
        cin >> n >> s >> cnt;
        for (int i = 1; i <= n; i++) {
            G[i].clear();
        }
        for (int i = 1; i < n; i++) {
            int x, y, w;
            cin >> x >> y >> w;
            G[x].push_back({y, w});
            G[y].push_back({x, w});
        }
        dfs(s, 0);
        cout << dp[s][cnt] << '\n';
    }
    return 0;
}
```

## E. 点对距离统计

对应题目：[Codeforces 161D - Distance in Tree](https://codeforces.com/problemset/problem/161/D)

### 题意简述

给定一棵包含 $n$ 个节点的无权树，统计树上距离恰好为 $k$ 的无序点对数量。

### 解题思路

任选一个节点作为根。定义 $dp_{u,d}$ 表示节点 $u$ 的子树中，与 $u$ 的距离恰好为 $d$ 的节点数量。初始状态为：

$$
dp_{u,0}=1
$$

处理节点 $u$ 的子节点 $v$ 时，先统计端点分别位于“已经合并的部分”和“$v$ 的子树”中的点对。若一个端点到 $u$ 的距离为 $d$，另一个端点到 $v$ 的距离必须为 $k-d-1$，其中额外的 $1$ 对应边 $(u,v)$：

$$
ans\leftarrow ans+dp_{u,d}\times dp_{v,k-d-1}
$$

完成点对统计后，再将 $v$ 的状态合并到 $u$：

$$
dp_{u,d+1}\leftarrow dp_{u,d+1} + dp_{v,d}
$$

必须先统计答案、后合并状态，否则同一棵子树中的点可能被重复计算。由于每一对节点在其最近公共祖先处恰好统计一次，因此不会重计或漏计。

### 复杂度分析

每条父子边合并时枚举至多 $k$ 个距离，时间复杂度为 $O(nk)$，空间复杂度为 $O(nk)$。

### AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 50010, K = 510;
int n, k, dp[N][K];
long long ans;
vector<int> G[N];
void dfs(int x, int fa) {
    dp[x][0] = 1;
    for (int y : G[x]) {
        if (y == fa) continue;
        dfs(y, x);
        for (int i = 0; i < k; i++) {
            ans += 1LL * dp[x][i] * dp[y][k - i - 1];
        }
        for (int i = 0; i < k; i++) {
            dp[x][i + 1] += dp[y][i];
        }
    }
}
int main() {
    cin >> n >> k;
    for (int i = 1; i < n; i++) {
        int x, y;
        cin >> x >> y;
        G[x].push_back(y);
        G[y].push_back(x);
    }
    dfs(1, 0);
    cout << ans << '\n';
    return 0;
}
```

## F. 树点改色

对应题目：[Codeforces 734E - Anton and Tree](https://codeforces.com/problemset/problem/734/E)

### 题意简述

给定一棵节点颜色为黑色或白色的树。一次操作可以选择一个同色连通块，将其中所有节点的颜色同时翻转。求将整棵树变为同一种颜色所需的最少操作次数。

### 解题思路

首先将颜色相同且相互连通的节点缩成一个点。由于原图是一棵树，缩点后仍然是一棵树，并且任意两个相邻组件的颜色必然不同。

设缩点树的直径长度为 $d$。如果从缩点树直径的中点附近开始翻转颜色，每次操作都可以将已经统一的区域向外扩展一层。最坏方向需要覆盖的层数由直径两端决定，因此最少操作次数为直径长度的一半向上取整：

$$
ans=\left\lceil\frac{d}{2}\right\rceil=\frac{d+1}{2}
$$

缩点后使用两次 BFS 求树的直径：第一次从任意组件出发找到最远组件 $u$，第二次从 $u$ 出发得到的最大距离即为直径。

### 复杂度分析

同色连通块缩点和两次 BFS 都只会线性处理节点与边，时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。

### AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, a[200010], b[200010], dis[200010];
vector<int> G[200010], G2[200010];
int find(int i, int &mx) {
    memset(dis, -1, sizeof(dis));
    queue<int> q;
    q.push(i);
    dis[i] = 0;
    int ans = i;
    while (!q.empty()) {
        int x = q.front();
        q.pop();
        if (dis[x] > dis[ans]) {
            ans = x;
        }
        for (int y : G2[x]) {
            if (dis[y] != -1) continue;
            dis[y] = dis[x] + 1;
            q.push(y);
        }
    }
    mx = dis[ans];
    return ans;
}
int main() {
    memset(b, -1, sizeof(b));
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    for (int i = 1; i < n; i++) {
        int x, y;
        cin >> x >> y;
        G[x].push_back(y);
        G[y].push_back(x);
    }
    int cnt = 0;
    for (int i = 1; i <= n; i++) {
        if (b[i] != -1) continue;
        queue<int> q;
        q.push(i);
        b[i] = cnt;
        while (!q.empty()) {
            int x = q.front();
            q.pop();
            for (int y : G[x]) {
                if (b[y] != -1 || a[y] != a[x]) continue;
                b[y] = cnt;
                q.push(y);
            }
        }
        cnt++;
    }
    for (int i = 1; i <= n; i++) {
        for (int x : G[i]) {
            if (b[i] == b[x]) continue;
            G2[b[i]].push_back(b[x]);
        }
    }
    int d = 0;
    find(find(0, d), d);
    cout << (d + 1) / 2 << '\n';
    return 0;
}
```
