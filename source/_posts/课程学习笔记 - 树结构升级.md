# 课程学习笔记 - 树结构升级

本节围绕树形动态规划、换根动态规划、树上背包、同色连通块缩点以及树的直径展开。树上问题通常没有完全统一的状态设计，但核心方法较为稳定：先选定根节点，将无根树转化为有根树，再根据“子树内信息如何合并”以及“父节点信息如何下传”设计状态与转移。

## A. 间隔选点-树上版本

对应题目：[HDU 1520 - Anniversary party](https://acm.hdu.edu.cn/showproblem.php?pid=1520) or [没有上司的舞会](https://www.luogu.com.cn/problem/P1352)

### 题意简述

给出一棵包含 $n$ 个点的树以及 $n$ 个点的权值 $a_i$，需要选出一个点集，满足点集中任意两点之间没有边**直接**相连（可以间接相连），求能够选出点集中最大的点权和。

### 解题思路

定义 $dp_{i,\{0,1\}}$ 表示当前点选/不选的子树答案，那么根据题目可以推出转移式（$son(i)$ 返回 $i$ 的子节点集，下同）：
$$
dp_{i,0}\leftarrow dp_{i,0}+\sum_{j \ \in \ son(i)}\max(dp_{j,0},dp_{j,1})\\
dp_{i,1}\leftarrow dp_{i,1}+\sum_{j \ \in \ son(i)}dp_{j,0}
$$
根据转移式转移即可，注意在遍历新点时需初始化状态 $dp_{i,0}=0,dp_{i,1}=a_i$，以及遍历子节点时去除父亲。

### 复杂度分析

每个节点和每条边均只被处理常数次，时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。

### AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 6010;
int n, a[N], dp[N][2];
vector<int> G[N];
void dfs(int x, int fa) {
    dp[x][0] = 0;
    dp[x][1] = a[x];
    for (int y : G[x]) {
        if (y == fa) {
            continue;
        }
        dfs(y, x);
        dp[x][0] += max(dp[y][0], dp[y][1]);
        dp[x][1] += dp[y][0];
    }
}
int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        G[u].push_back(v);
        G[v].push_back(u);
    }
    dfs(1, 0);
    cout << max(dp[1][0], dp[1][1]) << '\n';
    return 0;
}
```

## B. 苹果树

对应题目：[2486 -- Apple Tree](http://poj.org/problem?id=2486) or [Apple Tree - POJ 2486 - Virtual Judge](https://vjudge.net/problem/POJ-2486)

### 题意简述

给定一棵 $n$ 个节点的树，节点带权。从节点 $1$ 出发，最多移动 $k$ 条边，同一条边允许重复经过，求访问到的不同节点的最大点权和。

### 解题思路

设 $dp_{i,j,0}$ 表示从 $i$ 出发，在其子树内移动 $j$ 步且最终回到 $i$ 时能够获得的最大点权和；$dp_{i,j,1}$ 表示移动 $j$ 步且最终不必回到 $i$ 时的最大点权和。

答案即 $\max_{i=1}^k(dp_{1,i,1})$。（$dp_{\cdots,0}$ 被包含在 $dp_{\cdots,1}$ 里面了）

转移式：
$$
dp_{x,i+j+2,0}\leftarrow \max(dp_{x,i+j+2,0},dp_{x,i,0}+dp_{y,j,0})
\\
dp_{x,i+j+2,1}\leftarrow \max(dp_{x,i+j+2,1},dp_{x,i,1}+dp_{y,j,0})
\\
dp_{x,i+j+1,1}\leftarrow \max(dp_{x,i+j+1,1},dp_{x,i,0}+dp_{y,j,1})
\\
(y\in son(x),i\in[0,k],j\in[0,k-i-\{1,2\}])
$$
解释：

对于第一个转移，路径需要回到 $x$，那么可拆分为：$x$ 的其他子树（$dp_{x,i,0}$），$y$ 的子树（$dp_{y,j,0}$）以及 $x,y$ 之间的两次往返（$i+j+\Large2$）。

对于第二个转移，在第一个转移的基础上将其他子树调为无需返回，相当于：$x\rightarrow y\rightarrow dp_{y,j,0}\rightarrow y\rightarrow x\rightarrow dp_{x,i,1}$（可以看出同样 $x\rightarrow y$ 两次）。

对于第三个转移，因为原状态的 ${0/1}$ 由 $y$ 的子树决定，所以原状态为 $1$，相当于：$x\rightarrow dp_{x,i,0}\rightarrow x\rightarrow y\rightarrow dp_{y,j,1}$（可以看出 $x\rightarrow y$ 仅一次）。

注意因为更新会影响到后面的状态，所以需要倒序更新（类似背包，具体见代码）。

### 复杂度分析

每个节点在合并子树时枚举两部分步数，时间复杂度为 $O(nk^2)$，空间复杂度为 $O(nk)$。

### AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const int INF = 1000000000;
int n, k, a[110], dp[110][210][2];
vector<int> G[110];
void dfs(int x, int fa) {
    for (int i = 0; i <= k; i++) {
        dp[x][i][0] = dp[x][i][1] = -INF;
    }
    dp[x][0][0] = dp[x][0][1] = a[x];
    for (auto y : G[x]) {
        if (y == fa) continue;
        dfs(y, x);
        for (int i = k; i >= 0; i--) {
            for (int j = 0; i + j + 2 <= k; j++) {
                dp[x][i + j + 2][0] = max(dp[x][i + j + 2][0], dp[x][i][0] + dp[y][j][0]);
                dp[x][i + j + 2][1] = max(dp[x][i + j + 2][1], dp[x][i][1] + dp[y][j][0]);
            }
            for (int j = 0; i + j + 1 <= k; j++) {
                dp[x][i + j + 1][1] = max(dp[x][i + j + 1][1], dp[x][i][0] + dp[y][j][1]);
            }
        }
    }
}
int main() {
    cin >> n >> k;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    for (int i = 1, x, y; i < n; i++) {
        cin >> x >> y;
        G[x].push_back(y);
        G[y].push_back(x);
    }
    dfs(1, 0);
    int mx = 0;
    for (int i = 0; i <= k; i++) {
        mx = max(mx, dp[1][i][1]);
    }
    cout << mx;
    return 0;
}
```

## C. 树上最远距离

对应题目：[Problem - 2196](https://acm.hdu.edu.cn/showproblem.php?pid=2196) or [Computer - HDU 2196 - Virtual Judge](https://vjudge.net/problem/HDU-2196)

### 题意简述

给出一棵 $n$ 个节点的树，求每个节点能够到达的最远节点与其的距离。

### 解题思路

发现一个点的最远点只有两种情况：一种是在该点子树内，一种是在子树外。

那么可以维护 $d1,d2$ 表示子树内的最大与次大，$up$ 表示子树外的最大，用 $dfs$ 维护即可。

更具体地，第一次 DFS 自底向上计算每个节点向子树方向延伸的最大距离 $d1$ 和次大距离 $d2$，并记录最大距离来自哪个子节点。第二次 DFS 自顶向下计算 $up$：当最大子树贡献来自当前子节点时，必须改用次大值，否则会重复进入该子节点的子树。

节点 $u$ 的最终答案为 $\max(d1_u,up_u)$。这一过程是典型的换根动态规划。

### 复杂度分析

两次 DFS 均为线性遍历，时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。

### AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int n, d1[10010], d2[10010], up[10010], son[10010];
vector<pair<int, int>> G[10010];
void dfs1(int u, int fa) {
    for (auto x : G[u]) {
        int v = x.first, w = x.second;
        if (v == fa) continue;
        dfs1(v, u);
        int val = d1[v] + w;
        if (val > d1[u]) {
            d2[u] = d1[u];
            d1[u] = val;
            son[u] = v;
        } else if (val > d2[u]) {
            d2[u] = val;
        }
    }
}
void dfs2(int u, int fa) {
    for (auto x : G[u]) {
        int v = x.first, w = x.second;
        if (v == fa) continue;
        up[v] = max(up[u], (son[u] == v ? d2[u] : d1[u])) + w;
        dfs2(v, u);
    }
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    while (cin >> n) {
        for (int i = 1; i <= n; i++) {
            G[i].clear();
            d1[i] = d2[i] = up[i] = son[i] = 0;
        }
        for (int i = 2, parent, weight; i <= n; i++) {
            cin >> parent >> weight;
            G[parent].push_back({i, weight});
            G[i].push_back({parent, weight});
        }
        dfs1(1, 0);
        dfs2(1, 0);
        for (int i = 1; i <= n; i++) {
            cout << max(d1[i], up[i]) << '\n';
        }
    }
    return 0;
}
```

## D. 机器扫边

对应题目：[HDU 4003 - Find Metal Mineral](https://acm.hdu.edu.cn/showproblem.php?pid=4003) or [Virtual Judge](https://vjudge.net/problem/HDU-4003)

### 题意简述

给定一棵包含 $n$ 个节点的带权树，有 $k$ 个机器人从节点 $s$ 同时出发。要求所有边都至少被一个机器人经过，机器人不必返回起点，求所有机器人移动距离之和的最小值。

### 解题思路

以 $s$ 为根。定义 $dp_{u,j}$ 表示遍历完节点 $u$ 的整棵子树，并且最终有 $j$ 个机器人停留在该子树内时的最小代价。

处理叶节点时，不需要经过任何子树边，因此对任意 $j$ 都有 $dp_{u,j}=0$。

考虑合并 $u$ 的一个子节点 $v$，边权为 $w$。设总共需要在合并后的子树中留下 $j$ 个机器人，其中有 $p$ 个机器人进入 $v$ 的子树：

1. 当 $p=0$ 时，仍然需要遍历 $v$ 的子树，但进入该子树的机器人最后必须返回 $u$，边 $(u,v)$ 会被经过两次，代价增加 $dp_{v,0}+2w$；
2. 当 $p>0$ 时，有 $p$ 个机器人最终停留在 $v$ 的子树中。这 $p$ 个机器人都需要从 $u$ 经过边 $(u,v)$，代价增加 $dp_{v,p}+pw$。

因此，树上分组背包转移为：

$$
nw_j=\min\left(dp_{u,j}+dp_{v,0}+2w,\min_{1\le p\le j}\{dp_{u,j-p}+dp_{v,p}+pw\}\right)
$$

每次合并必须使用临时数组，避免本轮已经更新的状态再次参与转移。最终答案为 $dp_{s,k}$。

### 复杂度分析

每次合并枚举当前机器人数量和分配给子树的机器人数量，时间复杂度为 $O(nk^2)$，空间复杂度为 $O(nk)$。

### AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 10010, K = 12, INF = 0x3f3f3f3f;
struct Edge {
    int to, w;
};
int n, s, cnt, dp[N][K];
vector<Edge> G[N];
void dfs(int x, int fa) {
    for (int j = 0; j <= cnt; j++) {
        dp[x][j] = 0;
    }
    for (auto e : G[x]) {
        int y = e.to, w = e.w;
        if (y == fa) continue;
        dfs(y, x);
        int nxt[K];
        fill(nxt, nxt + cnt + 1, INF);
        for (int j = 0; j <= cnt; j++) {
            nxt[j] = min(nxt[j], dp[x][j] + dp[y][0] + 2 * w);
            for (int k = 1; k <= j; k++) {
                nxt[j] = min(nxt[j], dp[x][j - k] + dp[y][k] + k * w);
            }
        }
        for (int j = 0; j <= cnt; j++) {
            dp[x][j] = nxt[j];
        }
    }
}
int main() {
    int T = 1;
    // cin >> T;
    while (T--) {
        cin >> n >> s >> cnt;
        for (int i = 1; i <= n; i++) {
            G[i].clear();
        }
        for (int i = 1; i < n; i++) {
            int x, y, w;
            cin >> x >> y >> w;
            G[x].push_back({y, w});
            G[y].push_back({x, w});
        }
        dfs(s, 0);
        cout << dp[s][cnt] << '\n';
    }
    return 0;
}
```

## E. 点对距离统计

对应题目：[Codeforces 161D - Distance in Tree](https://codeforces.com/problemset/problem/161/D)

### 题意简述

给定一棵包含 $n$ 个节点的无权树，统计树上距离恰好为 $k$ 的无序点对数量。

### 解题思路

任选一个节点作为根。定义 $dp_{u,d}$ 表示节点 $u$ 的子树中，与 $u$ 的距离恰好为 $d$ 的节点数量。初始状态为：

$$
dp_{u,0}=1
$$

处理节点 $u$ 的子节点 $v$ 时，先统计端点分别位于“已经合并的部分”和“$v$ 的子树”中的点对。若一个端点到 $u$ 的距离为 $d$，另一个端点到 $v$ 的距离必须为 $k-d-1$，其中额外的 $1$ 对应边 $(u,v)$：

$$
ans\leftarrow ans+dp_{u,d}\times dp_{v,k-d-1}
$$

完成点对统计后，再将 $v$ 的状态合并到 $u$：

$$
dp_{u,d+1}\leftarrow dp_{u,d+1} + dp_{v,d}
$$

必须先统计答案、后合并状态，否则同一棵子树中的点可能被重复计算。由于每一对节点在其最近公共祖先处恰好统计一次，因此不会重计或漏计。

### 复杂度分析

每条父子边合并时枚举至多 $k$ 个距离，时间复杂度为 $O(nk)$，空间复杂度为 $O(nk)$。

### AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 50010, K = 510;
int n, k, dp[N][K];
long long ans;
vector<int> G[N];
void dfs(int x, int fa) {
    dp[x][0] = 1;
    for (int y : G[x]) {
        if (y == fa) continue;
        dfs(y, x);
        for (int i = 0; i < k; i++) {
            ans += 1LL * dp[x][i] * dp[y][k - i - 1];
        }
        for (int i = 0; i < k; i++) {
            dp[x][i + 1] += dp[y][i];
        }
    }
}
int main() {
    cin >> n >> k;
    for (int i = 1; i < n; i++) {
        int x, y;
        cin >> x >> y;
        G[x].push_back(y);
        G[y].push_back(x);
    }
    dfs(1, 0);
    cout << ans << '\n';
    return 0;
}
```

## F. 树点改色

对应题目：[Codeforces 734E - Anton and Tree](https://codeforces.com/problemset/problem/734/E)

### 题意简述

给定一棵节点颜色为黑色或白色的树。一次操作可以选择一个同色连通块，将其中所有节点的颜色同时翻转。求将整棵树变为同一种颜色所需的最少操作次数。

### 解题思路

首先将颜色相同且相互连通的节点缩成一个点。由于原图是一棵树，缩点后仍然是一棵树，并且任意两个相邻组件的颜色必然不同。

设缩点树的直径长度为 $d$。如果从缩点树直径的中点附近开始翻转颜色，每次操作都可以将已经统一的区域向外扩展一层。最坏方向需要覆盖的层数由直径两端决定，因此最少操作次数为直径长度的一半向上取整：

$$
ans=\left\lceil\frac{d}{2}\right\rceil=\frac{d+1}{2}
$$

缩点后使用两次 BFS 求树的直径：第一次从任意组件出发找到最远组件 $u$，第二次从 $u$ 出发得到的最大距离即为直径。

### 复杂度分析

同色连通块缩点和两次 BFS 都只会线性处理节点与边，时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。

### AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, a[200010], b[200010], dis[200010];
vector<int> G[200010], G2[200010];
int find(int i, int &mx) {
    memset(dis, -1, sizeof(dis));
    queue<int> q;
    q.push(i);
    dis[i] = 0;
    int ans = i;
    while (!q.empty()) {
        int x = q.front();
        q.pop();
        if (dis[x] > dis[ans]) {
            ans = x;
        }
        for (int y : G2[x]) {
            if (dis[y] != -1) continue;
            dis[y] = dis[x] + 1;
            q.push(y);
        }
    }
    mx = dis[ans];
    return ans;
}
int main() {
    memset(b, -1, sizeof(b));
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    for (int i = 1; i < n; i++) {
        int x, y;
        cin >> x >> y;
        G[x].push_back(y);
        G[y].push_back(x);
    }
    int cnt = 0;
    for (int i = 1; i <= n; i++) {
        if (b[i] != -1) continue;
        queue<int> q;
        q.push(i);
        b[i] = cnt;
        while (!q.empty()) {
            int x = q.front();
            q.pop();
            for (int y : G[x]) {
                if (b[y] != -1 || a[y] != a[x]) continue;
                b[y] = cnt;
                q.push(y);
            }
        }
        cnt++;
    }
    for (int i = 1; i <= n; i++) {
        for (int x : G[i]) {
            if (b[i] == b[x]) continue;
            G2[b[i]].push_back(b[x]);
        }
    }
    int d = 0;
    find(find(0, d), d);
    cout << (d + 1) / 2 << '\n';
    return 0;
}
```

## G. 树的直径-加强版

对应题目：[P3304 $[$SDOI2013$]$ 直径 - 洛谷](https://www.luogu.com.cn/problem/P3304)

### 题意简述

给定一棵带正边权的树。树上两个节点之间的最长距离称为树的直径长度。除了求出直径长度，还要求统计有多少条边被所有可能的直径共同经过。

### 解题思路

先用两次树上遍历求出一条直径。第一次从任意节点出发找到最远点 $s$，第二次从 $s$ 出发找到最远点 $t$，则 $s$ 到 $t$ 的路径是一条直径，长度记为 $D$。

将这条直径上的节点依次记为：

$$
p_0=s,p_1,\ldots,p_k=t
$$

设 $dis_i$ 表示 $s$ 到 $p_i$ 的距离，$h_i$ 表示从 $p_i$ 出发、不经过直径上的边，能够到达的最远距离。由于 $s$ 和 $t$ 已经是一对直径端点，一定有：

$$
h_i\le dis_i,\qquad h_i\le D-dis_i
$$

如果 $h_i=dis_i$，说明可以在 $p_i$ 的直径外子树中找到一个节点代替端点 $s$，并与 $t$ 构成另一条长度仍为 $D$ 的直径。因此，$p_0$ 到 $p_i$ 之间的边不可能被所有直径共同经过。令满足 $h_i=dis_i$ 的最靠右位置为 $L$。

同理，如果 $h_i=D-dis_i$，说明可以用 $p_i$ 外侧的节点代替端点 $t$。令满足该条件的最靠左位置为 $R$。

那么所有直径的公共部分恰好是 $p_L$ 到 $p_R$ 之间的路径，公共边数为：

$$
R-L
$$

遍历直径上每个节点的非直径子树即可求出对应的 $h_i$。这些子树互不相交，因此总遍历量仍然是线性的。

### 复杂度分析

求直径、还原直径路径和遍历所有非直径子树都只会线性访问节点与边，时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。

### AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const int N = 200010;
struct Edge {
    int to;
    ll w;
};
int n, fa[N];
ll faw[N], dis[N];
bool flg[N];
vector<Edge> G[N];
int walk(int s, bool f) {
    fill(dis + 1, dis + n + 1, -1);
    vector<int> st;
    st.push_back(s);
    dis[s] = 0;
    if (f) fa[s] = 0;
    int ans = s;
    while (!st.empty()) {
        int x = st.back();
        st.pop_back();
        if (dis[x] > dis[ans]) ans = x;
        for (Edge e : G[x]) {
            if (dis[e.to] != -1) continue;
            dis[e.to] = dis[x] + e.w;
            if (f) {
                fa[e.to] = x;
                faw[e.to] = e.w;
            }
            st.push_back(e.to);
        }
    }
    return ans;
}
int main() {
    cin >> n;
    for (int i = 1; i < n; i++) {
        int x, y;
        ll w;
        cin >> x >> y >> w;
        G[x].push_back({y, w});
        G[y].push_back({x, w});
    }
    int s = walk(1, false);
    int t = walk(s, true);
    ll d = dis[t];
    vector<int> p;
    for (int x = t; x != 0; x = fa[x]) {
        p.push_back(x);
    }
    reverse(p.begin(), p.end());
    for (int x : p) flg[x] = true;
    vector<ll> h(p.size(), 0);
    for (int i = 0; i < (int)p.size(); i++) {
        int root = p[i];
        for (Edge fir : G[root]) {
            if (flg[fir.to]) continue;
            struct State {
                int x, fa;
                ll dis;
            };
            vector<State> st;
            st.push_back({fir.to, root, fir.w});
            while (!st.empty()) {
                State cur = st.back();
                st.pop_back();
                h[i] = max(h[i], cur.dis);
                for (Edge e : G[cur.x]) {
                    if (e.to == cur.fa || flg[e.to]) continue;
                    st.push_back({e.to, cur.x, cur.dis + e.w});
                }
            }
        }
    }
    int l = 0, r = p.size() - 1;
    for (int i = 0; i < p.size(); i++) {
        if (h[i] == dis[p[i]]) l = i;
    }
    for (int i = 0; i < p.size(); i++) {
        if (h[i] == d - dis[p[i]]) {
            r = i;
            break;
        }
    }
    cout << d << '\n' << r - l << '\n';
    return 0;
}
```

## H. 动态树直径

对应题目：[Problem - 379F - Codeforces](https://codeforces.com/problemset/problem/379/F)

### 题意简述

初始有一棵包含四个节点的树，其中 $2,3,4$ 都与节点 $1$ 相连。每次操作给出当前的一片叶子 $v$，向树中加入两个新节点，并分别用一条边连接到 $v$。每次操作后输出当前树的直径长度。

### 解题思路

树的直径可以用两个端点 $a,b$ 表示，当前直径长度为 $d=dist(a,b)$。加入一个新节点 $x$ 后，新直径只有三种可能：

1. 仍然是原来的 $a$ 到 $b$；
2. 变为 $x$ 到 $a$；
3. 变为 $x$ 到 $b$。

因此只需要计算 $dist(x,a)$ 和 $dist(x,b)$，如果其中某个距离大于当前直径，就用 $x$ 替换直径的另一个端点。

一次操作加入的两个节点互为兄弟，它们到所有旧节点的距离完全相同，而二者之间的距离恒为 $2$。初始直径已经为 $2$，所以只检查其中一个新节点即可。

由于树只会添加叶子，可以在节点加入时立即维护其深度和倍增祖先。两点距离通过 LCA 计算：

$$
dis(x,y)=dep_x+dep_y-2dep_{LCA(x,y)}
$$

### 复杂度分析

每次添加节点需要预处理 $O(\log n)$ 个祖先，计算常数次 LCA，单次操作时间复杂度为 $O(\log n)$。总时间复杂度为 $O(q\log q)$，空间复杂度为 $O(q\log q)$。

### AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 1000010, LOG = 21;
int q, cnt = 4, dep[N], up[N][LOG];
void add(int x, int fa) {
    dep[x] = dep[fa] + 1;
    up[x][0] = fa;
    for (int i = 1; i < LOG; i++) {
        up[x][i] = up[up[x][i - 1]][i - 1];
    }
}
int lca(int x, int y) {
    if (dep[x] < dep[y]) swap(x, y);
    int num = dep[x] - dep[y];
    for (int i = 0; i < LOG; i++) {
        if (num >> i & 1) x = up[x][i];
    }
    if (x == y) return x;
    for (int i = LOG - 1; i >= 0; i--) {
        if (up[x][i] != up[y][i]) {
            x = up[x][i];
            y = up[y][i];
        }
    }
    return up[x][0];
}
int calc(int x, int y) {
    return dep[x] + dep[y] - 2 * dep[lca(x, y)];
}
int main() {
    up[1][0] = 1;
    for (int i = 1; i < LOG; i++) up[1][i] = 1;
    add(2, 1);
    add(3, 1);
    add(4, 1);
    int enda = 2, endb = 3, d = 2;
    cin >> q;
    while (q--) {
        int fa;
        cin >> fa;
        int nw = ++cnt;
        add(nw, fa);
        add(++cnt, fa);
        int disa = calc(nw, enda);
        int disb = calc(nw, endb);
        if (disa > d) {
            endb = nw;
            d = disa;
        } else if (disb > d) {
            enda = nw;
            d = disb;
        }
        cout << d << '\n';
    }
    return 0;
}
```

## I. 不相交路径

对应题目：[Problem - 4912](https://acm.hdu.edu.cn/showproblem.php?pid=4912)

### 题意简述

给定一棵树和 $m$ 条指定路径，第 $i$ 条路径连接节点 $u_i$ 与 $v_i$。从这些路径中选择尽可能多的路径，使任意两条被选路径都没有公共节点，求最多能够选择多少条。

### 解题思路

将树根设为节点 $1$。对于一条路径 $(u,v)$，路径上深度最小的节点就是 $LCA(u,v)$。按照 LCA 深度从大到小处理所有路径，优先选择位置更深、影响范围更小的路径。

假设当前选择了路径 $(u,v)$，其最近公共祖先为 $l$。之后处理的路径 $P$ 的 LCA 深度不会大于 $l$：

- 如果 $P$ 的某个端点位于 $l$ 的子树内，那么 $P$ 想要到达子树外部，或让自己的 LCA 不高于 $l$，都必然经过节点 $l$，因此会与当前路径相交；
- 如果 $P$ 的两个端点都不在 $l$ 的子树内，那么整条路径不会进入 $l$ 的子树，也就不会与当前路径相交。

因此，选择一条路径后，可以直接将其 LCA 的整棵子树标记为不可用。处理下一条路径时，只需判断它的两个端点是否已经被标记：若都未被标记，就选择该路径并标记其 LCA 子树。

使用 DFS 序后，一棵子树对应连续区间 $[dfn_l,out_l]$。通过树状数组维护区间加、单点查询，即可完成子树标记与端点检查。

### 复杂度分析

预处理倍增祖先和所有路径的 LCA 需要 $O((n+m)\log n)$ 时间，排序需要 $O(m\log m)$ 时间，每条路径进行常数次树状数组操作，空间复杂度为 $O(n\log n+m)$。

### AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005, L = 18;
struct node {
	int x, y, z;
} p[N];
int n, m, h[N], to[N << 1], nx[N << 1], ec, f[N][L], d[N], dfn[N], out[N], cur[N], st[N], top, tim, tr[N];
void ae(int x, int y) {
	to[++ec] = y, nx[ec] = h[x], h[x] = ec;
}
void add(int x, int v) {
	for (; x <= n; x += x & -x)tr[x] += v;
}
int ask(int x) {
	int s = 0;
	for (; x; x -= x & -x)s += tr[x];
	return s;
}
void dfs() {
	tim = top = 0;
	for (int i = 0; i < L; i++)f[1][i] = 1;
	st[++top] = 1;
	while (top) {
		int x = st[top];
		if (!dfn[x])dfn[x] = ++tim, cur[x] = h[x];
		int &i = cur[x];
		while (i && to[i] == f[x][0])i = nx[i];
		if (!i) {
			out[x] = tim;
			top--;
			continue;
		}
		int y = to[i];
		i = nx[i];
		d[y] = d[x] + 1, f[y][0] = x;
		for (int j = 1; j < L; j++)f[y][j] = f[f[y][j - 1]][j - 1];
		st[++top] = y;
	}
}
int lca(int x, int y) {
	if (d[x] < d[y])swap(x, y);
	int k = d[x] - d[y];
	for (int i = 0; i < L; i++)if (k >> i & 1)x = f[x][i];
	if (x == y)return x;
	for (int i = L - 1; i >= 0; i--)
		if (f[x][i] != f[y][i])x = f[x][i], y = f[y][i];
	return f[x][0];
}
bool cmp(node a, node b) {
	return d[a.z] > d[b.z];
}
int main() {
	while (cin >> n >> m) {
		memset(h, 0, sizeof(int) * (n + 1));
		memset(d, 0, sizeof(int) * (n + 1));
		memset(dfn, 0, sizeof(int) * (n + 1));
		memset(tr, 0, sizeof(int) * (n + 1));
		ec = 0;
		for (int i = 1, x, y; i < n; i++)
			cin >> x >> y, ae(x, y), ae(y, x);
		dfs();
		for (int i = 0; i < m; i++) {
			cin >> p[i].x >> p[i].y;
			p[i].z = lca(p[i].x, p[i].y);
		}
		sort(p, p + m, cmp);
		int ans = 0;
		for (int i = 0; i < m; i++) {
			int x = p[i].x, y = p[i].y, z = p[i].z;
			if (ask(dfn[x]) || ask(dfn[y]))continue;
			ans++;
			add(dfn[z], 1), add(out[z] + 1, -1);
		}
        cout << ans << "\n";
	}
	return 0;
}
```

## J. 次小生成树

对应题目：[P4180 [BJWC2010] 严格次小生成树 - 洛谷](https://www.luogu.com.cn/problem/P4180)

### 题意简述

给定一张无向带权连通图。定义严格次小生成树为边权和严格大于最小生成树，并且在所有满足条件的生成树中边权和最小的一棵，求其边权和。

### 解题思路

先用 Kruskal 算法求出一棵最小生成树，权值和记为 $sum$，同时记录哪些边被选入生成树。

对于任意一条未被选入生成树的边 $(u,v,w)$，将它加入最小生成树后会形成一个环。若删除环上的一条树边，就能得到另一棵生成树。为了使新生成树尽可能小，应删除 $u$ 到 $v$ 路径上权值最大的、且严格小于 $w$ 的边，设其权值为 $x$，则候选答案为：

$$
sum+w-x
$$

不能只维护路径最大值。若路径最大边权恰好等于 $w$，替换后得到的仍然是一棵权值为 $sum$ 的最小生成树，不满足“严格次小”的要求。此时应删除路径上的严格次大边。

因此，对每个倍增区间维护两个值：区间内互不相同的最大边权和严格次大边权。查询路径时合并这些信息，即可得到路径上的最大值与严格次大值：

- 若最大值小于 $w$，删除最大值；
- 若最大值等于 $w$，删除严格次大值；
- 若不存在严格小于 $w$ 的边，则这条非树边不能产生严格更大的候选答案。

枚举所有非树边并取最小候选值即可。

### 复杂度分析

Kruskal 排序需要 $O(m\log m)$ 时间，倍增预处理需要 $O(n\log n)$ 时间，每条非树边查询一次路径信息需要 $O(\log n)$ 时间。总时间复杂度为 $O(m\log m+n\log n)$，空间复杂度为 $O(n\log n+m)$。

### AC代码

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;
const int N = 1e5 + 2;
const int M = 3e5 + 2;
const int K = 2e1 + 2;
const int MOD = 1e9 + 7;
const int T = N - 2;
const int INF = 0x3f3f3f3f;
const int LINF = 0x3f3f3f3f3f3f3f3f;
const double EPS = 1e-6;
int n, m, head[N], nxt[M << 1], to[M << 1], tot, dp[N][K], dep[N], pa[N], cnt;
int wt[M << 1], fst[N][K], snd[N][K], sum, ans = LINF;
bool mst[M];
struct Edge {
    int u, v;
    int w;
    void In() {
        cin >> u >> v >> w;
    }
    bool operator < (const Edge &cmp) const {
        return w < cmp.w;
    }
} edg[M];
inline int Find(int u) {
    return u == pa[u] ? u : pa[u] = Find(pa[u]);
}
inline void Merge(int u, int v) {
    int fu = Find(u), fv = Find(v);
    if (fu != fv) {
        pa[fu] = fv;
    }
}
inline void Add(int u, int v, int w) {
    nxt[++tot] = head[u], to[tot] = v, wt[tot] = w, head[u] = tot;
}
void Init(int u, int fa, int w) {
    dep[u] = dep[fa] + 1, dp[u][0] = fa, fst[u][0] = w, snd[u][0] = -LINF;
    for (int i = 1; i <= K - 2; i++) {
        dp[u][i] = dp[dp[u][i - 1]][i - 1];
        fst[u][i] = max(fst[u][i - 1], fst[dp[u][i - 1]][i - 1]);
        snd[u][i] = max({min(fst[u][i - 1], fst[dp[u][i - 1]][i - 1]), snd[u][i - 1], snd[dp[u][i - 1]][i - 1]});
    }
    for (int i = head[u]; ~i; i = nxt[i]) {
        int v = to[i];
        int w = wt[i];
        if (v != fa) {
            Init(v, u, w);
        }
    }
}
inline int Lca(int u, int v) {
    if (dep[u] < dep[v]) {
        swap(u, v);
    }
    if (dep[u] != dep[v]) {
        for (int i = K - 2; i >= 0; i--) {
            if (dep[dp[u][i]] >= dep[v]) {
                u = dp[u][i];
            }
        }
    }
    if (u != v) {
        for (int i = K - 2; i >= 0; i--) {
            if (dp[u][i] != dp[v][i]) {
                u = dp[u][i], v = dp[v][i];
            }
        }
        u = dp[u][0], v = dp[u][0];
    }
    return u;
}
inline int Replace(int u, int v, int rep) {
    int mx1 = -LINF, mx2 = -LINF;
    for (int i = K - 2; i >= 0; i--) {
        if (dep[dp[u][i]] >= dep[v]) {
            if (fst[u][i] > mx1) {
                mx2 = mx1;
                mx1 = fst[u][i];
            } else if (fst[u][i] > mx2 && fst[u][i] != mx1) {
                mx2 = fst[u][i];
            }
            if (snd[u][i] > mx2 && snd[u][i] != mx1) {
                mx2 = snd[u][i];
            }
            u = dp[u][i];
        }
    }
    if (mx1 == rep) {
        return mx2;
    }
    return mx1;
}
signed main() {
    memset(head, -1, sizeof(head));
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        pa[i] = i;
    }
    for (int i = 1; i <= m; i++) {
        edg[i].In();
    }
    sort(edg + 1, edg + m + 1);
    for (int i = 1; i <= m; i++) {
        int fu = Find(edg[i].u), fv = Find(edg[i].v);
        if (fu != fv) {
            Merge(edg[i].u, edg[i].v);
            Add(edg[i].u, edg[i].v, edg[i].w), Add(edg[i].v, edg[i].u, edg[i].w);
            sum += edg[i].w, cnt++;
            mst[i] = true;
        }
        if (cnt == n - 1) {
            break;
        }
    }
    Init(1, 0, 0);
    for (int i = 1; i <= m; i++) {
        if (!mst[i]) {
            int lca = Lca(edg[i].u, edg[i].v);
            int maxu = Replace(edg[i].u, lca, edg[i].w), maxv = Replace(edg[i].v, lca, edg[i].w);
            ans = min(ans, sum - max(maxu, maxv) + edg[i].w);
        }
    }
    cout << ans;
    return 0;
}
```
